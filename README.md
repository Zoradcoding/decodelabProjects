# 🔐 Cyber Security Projects

A collection of beginner-friendly cybersecurity projects developed using Python as part of the DecodeLabs Cyber Security Training Program. These projects focus on building core cybersecurity concepts through practical implementation and analysis.

---

## 📚 Projects Included

### 🔹 Project 1 – Password Strength Checker

A Python program that evaluates the strength of a user's password based on common security standards.

#### Features
- Check password length
- Detect uppercase and lowercase letters
- Detect numbers
- Detect special characters
- Classify passwords as Weak, Medium, or Strong

#### Skills Learned
- String manipulation
- Conditional statements
- Input validation
- Password security fundamentals

---

### 🔹 Project 2 – Basic Encryption & Decryption

A Python implementation of a simple Caesar Cipher that encrypts and decrypts user-provided text.

#### Features
- Encrypt plain text
- Decrypt encrypted text
- User-defined shift key
- Simple and easy-to-understand algorithm

#### Skills Learned
- Cryptography basics
- Caesar Cipher implementation
- String manipulation
- Programming logic

---

### 🔹 Project 3 – Phishing Awareness Analysis

A cybersecurity awareness project that analyzes suspicious emails and identifies phishing indicators.

#### Features
- Detect suspicious links
- Identify phishing keywords
- Highlight common red flags
- Explain why a message is unsafe
- Improve phishing awareness

#### Skills Learned
- Threat analysis
- Email security
- Social engineering awareness
- Cybersecurity best practices

```bash

```
